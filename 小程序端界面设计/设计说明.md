# 企业订购小程序 · 界面设计说明

> 红外测温枪 MES 系统 · 微信小程序端（首页 / 产品 / 询价单 / 我的）
> 设计稿 v1.0 · 2026.10 · 画布 375 × 812pt，2 倍图导出（750px 宽，长图展示）

## 一、整体定位

面向**企业客户的批量订购**通道：客户在小程序里查产品、加询价单、提交询价，销售在 MES 后台确认价格与交期，确认后转正式订单并生成生产工单。
视觉上延续「企业订购」现有风格：浅蓝底 + 白色大圆角卡片 + 蓝色主色，信息密度适中，适合采购人员快速下单。

## 三、页面说明

### 01 首页
- 结构：标题 → 搜索 → 主 Banner（成品与半成品批量订购 + 发起询价） → 四宫格快捷入口 → 可订购产品（全部 / 成品 / 半成品） → 大批量采购需求条 → tabbar
- 四宫格：批量询价、我的订单、交付进度、联系销售
- 产品卡：标签（成品/半成品）、名称、编码、一行规格、右侧「加入询价」

### 02 产品
- 结构：标题 + 搜索图标 → 搜索框 → 分类胶囊（全部/成品/半成品/电控组件/结构件） → 排序（综合 / 交付期 / 起订量 + 共 N 款） → 双列产品卡 → 样件与试产说明 → tabbar
- 产品卡：缩略图、成品/半成品角标、名称、编码、起订量 + 圆形「+」加入

### 03 询价单
- 结构：标题 + 管理 → 状态 tab（待提交 / 已提交 / 已报价） → 询价单卡（单号、可修改、3 个品项 + 数量步进器） → 采购需求卡（期望交期 / 收货地址 / 开票方式 / 备注） → 规则说明 → 底部提交栏 → tabbar
- 底部栏：品项数与总件数、预计交期、「提交询价」主按钮

### 04 我的
- 结构：企业信息头部（企业名 / 企业认证 / 采购员） → 数据卡（询价中 / 待确认 / 已成交） → 我的订单（待报价 / 待确认 / 生产中 / 已交付） → 常用服务六宫格 → 企业信息（信用代码 / 客户等级 / 专属销售） → 版本号 → tabbar

## 四、交互与状态约定

1. **加入询价单**：点击后 tabbar「询价单」角标 +1，并 toast「已加入询价单」；同一产品重复添加则数量累加。
2. **提交询价**：生成询价单号 `XJ + 日期 + 流水`，状态由「待提交」进入「已提交」，销售 2 小时内响应。
3. **状态流转**：待提交 → 已提交 → 已报价（7 天有效） → 客户确认 → 正式订单 → 生产中 → 已交付。
4. **成品 / 半成品**：用标签颜色区分，成品为蓝色系、半成品为蓝紫色系。
5. **空态**：询价单无数据时展示插画 + 「去挑选产品」按钮；订单无数据时引导「发起询价」。
