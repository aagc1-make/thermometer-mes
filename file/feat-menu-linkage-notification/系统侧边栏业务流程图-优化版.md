# 红外测温枪 MES 系统侧边栏业务流程图（优化版）

> **节点规则**：流程图中的矩形节点全部来自《系统侧边栏菜单结构.md》，严格保留现有菜单名称。业务状态、库存动作和放行条件只能写在箭头上，不作为新节点。  
> **箭头规则**：实线 `-->` 表示实际业务流转；虚线 `-.->` 表示基础配置、权限、资源或查询支撑；无可靠直接关系的菜单不强行连线。  
> **演示口径**：采购150件，生产10台，销售6台，成品仓结存4台，形成64条库存流水。

## 一、端到端核心业务流程

```mermaid
flowchart LR
    A1["供应商管理"] -->|确定供货方| A2["到货通知"]
    A2 -->|生成来料待检| A3["待检任务"]
    A3 -->|检验类型：IQC| A4["来料检验"]
    A4 -->|合格放行| A5["采购入库"]
    A4 -->|不合格退供| A6["采购退货"]
    A5 -->|原料仓增加150| A7["库存现有量"]

    B1["物料产品管理"] -->|展开多级BOM| B2["生产工单"]
    B3["工艺流程"] -.->|提供工序路线| B4["生产排产"]
    B2 -->|下达工单| B4
    B4 -->|生成9个任务| B5["生产领料"]
    B5 -->|原料仓转线边库| B6["生产报工"]
    B6 -->|关键工序送检| A3
    A3 -->|检验类型：IPQC| B7["过程检验"]
    B7 -->|合格后继续| B8["工序流转"]
    B6 -->|非检验工序直接流转| B8
    B8 -->|末工序完成| B9["产品入库"]
    B9 -->|成品仓增加10| A7

    C1["客户管理"] -->|确定收货客户| C2["发货通知单"]
    A7 -.->|校验可用库存| C2
    C2 -->|生成出货待检| A3
    A3 -->|检验类型：OQC| C3["出货检验"]
    C3 -->|合格放行| C4["销售出库"]
    C4 -->|成品仓减少6| A7

    A5 --> D1["库存流水"]
    B5 --> D1
    B9 --> D1
    C4 --> D1
    A7 -->|当前结存| D2["批次追溯"]
    D1 -->|历史流转| D2
```

### 核心放行规则

1. `来料检验`合格后才能进入`采购入库`；不合格时进入`采购退货`。
2. `生产排产`完成后才能执行`生产领料`；领料到线边库后才能进行`生产报工`。
3. 关键工序的`生产报工`进入`待检任务`，由`过程检验`合格后继续`工序流转`。
4. `发货通知单`进入`待检任务`，由`出货检验`合格后执行`销售出库`。
5. 所有库存增减均写入`库存流水`，并可通过`批次追溯`反查来源。

```mermaid

    I1["采购入库"] --> T["库存流水"]

    I3["杂项入库"] --> T
```

库存闭环要求：

- 每次库存增加、减少或库位转移都生成`库存流水`。
- `库存现有量`只表示当前结存，历史变化统一从`库存流水`查询。
- `批次追溯`同时使用当前库存和历史流水完成正向、反向追溯。
