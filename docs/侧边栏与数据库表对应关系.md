# MES 系统侧边栏与数据库表对应关系

> 数据库：`j2eedb`  
> 说明：本文件根据当前 `sys_menu` 菜单配置和实际数据库表整理。一级侧边栏是系统左侧的模块目录，二级侧边栏是模块下直接显示的菜单。主从业务同时列出主表、明细表和必要关联表。纯监控或聚合页面没有独立业务表时，会注明实际数据来源。
