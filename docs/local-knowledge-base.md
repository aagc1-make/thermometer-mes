# 智能助手本地知识库

## 使用

1. 在智能助手顶部打开“知识库”，点击“导入文档”。
2. 选择 TXT、MD、CSV、PDF 或 DOCX 文件，或切换“粘贴文本”。填写名称、分类、版本号，核对正文预览后确认导入。
3. 切换“知识问答”提问。结果是命中资料的原文片段，标注文件、版本及段落或页码；“查看原文”打开提取的正文并定位引用位置。
4. 检索只引用真正谈到该主题的片段：问「检验」「不合格处置」时，只共享“传感器”“红外”这类实体词的资料不会被当成引用。资料里确实没有该主题时，「检验项目」「不合格处置」两类业务问题会直接按系统实际流程和单据回答（见下节）；其他问题仍给出无结果提示，可改用文档中的物料、工序和检验项目关键词。不支持将本地关键词匹配当作语义向量检索。
5. 需要模型解释时，可使用已有“请求大模型分析”。确认框说明将发送当前问题及引用片段；不点击确认就不会调用模型，不会自动发送整份文档。

## 业务规则问答

系统流程类问题不依赖本机文档，回答来自真实配置与单据，只读、不产生任何写操作：

- **某物料来料检验要检查什么**：先读「质量管理 → 质检方案」为该物料配置的检测项（检验方法、合格范围、判定说明、检验工具）与判定参数；没配方案时引用最近一张来料检验单实际记录的检测项；两者都没有就说明系统只记录检测数量与合格/不合格数量，不编造项目。
- **不合格物料如何处理**：按发现环节给出系统真实路径（未入库退供、部分合格只入合格量、已入库退供、过程检验 NG 产出不入成品库、生产退料 RQC 拆分、客户退货），并汇总当前不合格数量与待执行退供单；明确说明系统没有独立报废单，报废需在「杂项出库」出账。
- 物料名不完全匹配时按相邻两字命中数排序，命中多个或为 0 时追问或说明，不用全部物料的结果顶替。
- 缺少 `mes:qc:iqc:list`、`mes:wm:rtvendor:list` 权限时，回答里直接说明“未读取”，不会写成“没有不合格”。


## 本地保存和版本

使用 IndexedDB 按登录账号区分存储。刷新页面保留，清空对话不删除资料；当前浏览器的资料不会同步到其它浏览器或设备。清理站点数据会删除资料，应保留原始文件。

同名称、同分类视为同一份资料，新版本导入成功后停用旧版。同版本重复导入会被拒绝；保存失败不改变原有启用状态。可手动启用历史版本；删除当前版本不自动回退。

引用以文档ID及版本精确查找。资料删除后，历史聊天仍保留当时的引用片段，查看原文会说明该版本已删除，不会打开其它版本替代。

## 范围

- 浏览器本地提取正文、分段和关键词检索，不新增后端接口、业务数据库表或向量服务，也不新增 npm 依赖。
- PDF复用项目自带PDF.js及中文CMap/标准字体；扫描图片不做OCR。DOCX仅提取正文和表格中的文字，不保留排版、宏和嵌入对象。
- DOCX使用浏览器原生DecompressionStream，兼容性不足时提示更新浏览器或粘贴正文。DOCX XML正文解压最多2 MiB；不处理加密或异常压缩档案。
- 文件上限5 MiB；正文每份30万字符、总量100万字符；最多40个文档版本；PDF最多200页。
- 上传控件关闭自动上传，导入内容通过Vue文本插值展示。实时业务模式与知识问答显式分开，文档文本不会触发单据执行。
